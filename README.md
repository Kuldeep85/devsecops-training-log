# DevSecOps Training Log

A personal 12-week learning log: Linux, Git, Docker, Kubernetes/OpenShift, CI/CD pipelines, Terraform and security scanning, with hands-on labs and evidence.

## How to use this repository
1. Follow [`setup/00-setup.md`](setup/00-setup.md) once (WSL, tools, GitHub, this repo).
2. Read [`setup/github-evidence-guide.md`](setup/github-evidence-guide.md): what to commit, what never to commit, and when to push.
3. Follow [`PLAN.md`](PLAN.md) day by day.

## What is inside
- `week-XX/day-NN-*.md` — one guided practice page per day, with your own notes added as you go
- `labs/` — scripts, Dockerfiles, YAML and Terraform you wrote
- `notes/` — weekly summaries and cheat sheets
- `interview/` — your interview answers and project story
- `tools/finish-day.sh` — scans for secrets, commits and pushes
