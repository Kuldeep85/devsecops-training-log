## How a normal day works
1. Open today's file in VS Code (`code .` from the repo folder).
2. Read **Why this matters** and **Goal**.
3. Run each block in the **Do this** section and read the output.
4. Do the **exercise without copying**. This is where the learning happens.
5. Fill in **My notes** in the file, save any listed artifacts under `labs/day-NN/`.
6. Run `tools/finish-day.sh NN "short message"` to scan for secrets, commit and push.

## When you fall behind
Skip nothing in Weeks 1–6. In Weeks 7–10 you may drop Days 41–42 (Azure identity and Key Vault) if you have no personal Azure subscription, and do the Terraform days locally. Do not skip the project (Week 6) or the interview days (Week 11).
