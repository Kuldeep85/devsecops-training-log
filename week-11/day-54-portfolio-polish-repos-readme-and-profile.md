# Day 54 — Portfolio polish: repos, README and profile

**Week 11 · about 60 minutes · Run in: VS Code + browser (GitHub)**

## Why this matters
A recruiter spends about a minute on your GitHub. Every repo should be tidy, honest and easy to understand.

## Goal today
Tidy the three repos and the GitHub profile.

## Do this (run each block, then read the output before moving on)
For each repo (`devsecops-training-log`, `devsecops-pipeline-lab`, `cicd-practice`, `terraform-lab`):

1. A README that starts with **what this is** in one sentence and says it is a learning project.
2. No secrets, tokens, client names, screenshots of client systems or employer data. Run: `gitleaks detect --source . --redact`.
3. A clear folder structure and a short 'how to run' section.
4. Repository description and topics set on GitHub (`devsecops`, `azure-devops`, `github-actions`, `docker`, `kubernetes`, `terraform`).
5. Pin the best three repos on your profile and write a two-line profile bio.
6. Check your **commit history is honest** (never backdate or fake commits).

## What you should see
Someone opening your profile understands in 60 seconds what you can do.

## Your exercise (type it yourself, don't copy)

2. Fix anything they misunderstood.
3. Add your GitHub link to your CV and LinkedIn.
